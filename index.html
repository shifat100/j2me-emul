J2ME KaiOS

Эмулятор Java ME (MIDP 2.0) для кнопочных телефонов KaiOS.

  • Список: крестовина — выбор, OK — запуск, LSK/Esc — добавить .jar, RSK/Назад — опции, 0–9 — T9 поиск.
  • В игре: крестовина и OK — джойстик, LSK/Esc — левая софт-клавиша, RSK/Назад — правая софт-клавиша, 0–9 * # — цифры, Backspace — C.
  • Настройки и полный экран: нажмите Вызов (или LSK+RSK / F10 / Tab) в игре — можно выбрать 128×160, 240×320, 320×240 или любой размер на весь экран.

Основан на pluotsorbet от Mozilla.

Нажмите левую софт-клавишу (или Esc), чтобы добавить .jar.
